# Changelog

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-06-21

### Added
- Curated directory of 37 Model Context Protocol (MCP) servers across 14
  categories, with official/auth/transport metadata.
- `mcp-dir` CLI: list, search, categories, stats, export (json/csv), generate.
- Auto-generated README, registry-integrity tests, and CI (incl. a check that
  the README stays in sync with the registry).
